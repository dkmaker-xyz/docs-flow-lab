Search runs as a separate service

Where search runs from v0.3.0; read before changing search.

On this page

  • Context
  • Decision
  • Rollout
  • Consequences

Context

Search inside the app process (ADR-0055) cannot keep up with the larger indexes planned for v0.3.0.

Decision

From v0.3.0, search runs as a separate service next to the app. The app calls it over HTTP. The service keeps its own index and is deployed with the same container base image as the app (TECH-0005).

Rollout

The service ships with v0.3.0; the in-process search is removed in the same release.

Consequences

  • One more service to deploy and monitor.
  • The app no longer holds the search index in memory.
