This code repository has two applications under `apps/`:

- `apps/web`: the web front end, a Node.js package (`package.json`) built into a container image (`Dockerfile`).
- `apps/integration2`: an integration service, a Maven project (`pom.xml`).

CI lives in `.github/workflows/`; `tech-check.yml` runs `idc365-decisions tech check` on every pull request, so every dependency must be on the approved tech stack.

Before changing an application, read its code documentation (`idc365-decisions code show apps/web/_`) and the decisions it links to.
